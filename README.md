# webside_t-shirt

ร้านขายส่งเสื้อฟุตบอล Khunakorn Sport — FastAPI + Jinja2

## ติดตั้งและรัน

```bash
python -m venv env
env/Scripts/activate
pip install -r requirements.txt
cd app
python -m uvicorn main:app --reload --port 8000
```

เปิด <http://localhost:8000>

## เข้าหน้าผู้ดูแล

`/admin/login` — ครั้งแรกระบบจะสุ่มรหัสผ่านให้ แล้ว**พิมพ์ในคอนโซลตอนสตาร์ต**
พร้อมเก็บไว้ที่ `app/_data/secrets.json`

เปลี่ยนรหัสผ่าน: แก้ค่า `admin_password` ในไฟล์นั้น แล้วรีสตาร์ตเซิร์ฟเวอร์
(ค่านี้อ่านตอนสตาร์ตครั้งเดียว — uvicorn `--reload` จับตาดูเฉพาะไฟล์ `.py`)

หน้าผู้ดูแลมี 2 ส่วน:

- `/admin/` — แก้ราคา รายละเอียด และรูปสินค้า
- `/admin/orders` — คำสั่งซื้อ · แจ้งชำระเงิน (ยืนยัน/ปฏิเสธสลิป) · ข้อความติดต่อ

## ขั้นตอนการชำระเงิน

```
ลูกค้าสั่งซื้อ           → สถานะ "รอชำระเงิน"
ลูกค้าแจ้งโอน + แนบสลิป  → สถานะ "รอตรวจสลิป"   (ผูกเลขที่คำสั่งซื้ออัตโนมัติ)
แอดมินกด "ยืนยันเงินเข้า" → สถานะ "ชำระแล้ว"
แอดมินกด "ปฏิเสธ"        → กลับเป็น "รอชำระเงิน"
```

ลูกค้าที่เคยสั่งซื้อจากเบราว์เซอร์เดิมจะเห็นเลขที่คำสั่งซื้อเป็นรายการให้เลือก
พร้อมเติมยอดเงินให้อัตโนมัติ ไม่ต้องพิมพ์เอง

## ตัวแปรสภาพแวดล้อม (env)

ไม่ตั้งก็รันได้ — ระบบจะใช้ค่าเริ่มต้นและสร้างความลับให้เอง
แต่ตอนขึ้นใช้งานจริงควรตั้งอย่างน้อยกลุ่มความปลอดภัย

### ความปลอดภัย

| ตัวแปร | ความหมาย |
|---|---|
| `SECRET_KEY` | กุญแจเซ็น session cookie |
| `ADMIN_USER` | ชื่อผู้ใช้แอดมิน (ค่าเริ่มต้น `admin`) |
| `ADMIN_PASSWORD_HASH` | ค่า hash ของรหัสผ่าน — **แนะนำสำหรับ production** |
| `ADMIN_PASSWORD` | รหัสผ่านแบบข้อความ (สะดวกตอนพัฒนา) |

สร้างค่า hash:

```bash
env/Scripts/python.exe -c "import sys; sys.path.insert(0,'app'); from config import hash_password; print(hash_password('รหัสที่ต้องการ'))"
```

### แจ้งเตือนเมื่อมีออเดอร์ / สลิปใหม่

ตั้งช่องทางไหนก็ได้ ตั้งหลายช่องพร้อมกันได้ ไม่ตั้งเลยก็ไม่ส่ง

| ตัวแปร | ความหมาย |
|---|---|
| `NOTIFY_WEBHOOK_URL` | Webhook ของ Discord / Slack / n8n / Make |
| `LINE_CHANNEL_TOKEN` | Channel access token ของ LINE Messaging API (broadcast) |
| `SITE_URL` | ที่อยู่เว็บ ใช้ทำลิงก์ในข้อความแจ้งเตือน |

> LINE Notify ปิดให้บริการไปแล้วเมื่อ 31 มี.ค. 2568 — ใช้ LINE Messaging API แทน

**อีเมลแจ้งเตือน** ตั้งค่าไว้ให้แล้วที่ `app/_data/secrets.json` ส่วน `smtp`
เหลือแค่ใส่ **App Password** ของ Gmail ในช่อง `app_password` แล้วรีสตาร์ทเซิร์ฟเวอร์

```jsonc
"smtp": {
  "host": "smtp.gmail.com",
  "port": 587,
  "user": "khunakr418@gmail.com",
  "app_password": "",          // <- ใส่ตรงนี้ (16 หลัก ไม่ใช่รหัส Gmail ปกติ)
  "from": "khunakr418@gmail.com",
  "to":   "khunakr418@gmail.com"
}
```

**ลำดับการเชื่อมต่อ Gmail**

1. เปิด **2-Step Verification** ที่ <https://myaccount.google.com/security>
   (ถ้าไม่เปิด จะไม่มีเมนู App Passwords ให้เลือก)
2. สร้าง App Password ที่ <https://myaccount.google.com/apppasswords>
   ตั้งชื่อว่าอะไรก็ได้ เช่น `Khunakorn Shop`
3. คัดลอกรหัส 16 หลักที่ได้ ไปวางในช่อง `app_password`
   (Google แสดงเป็น 4 กลุ่มมีเว้นวรรค — วางทั้งเว้นวรรคได้ ระบบตัดให้เอง)
4. **รีสตาร์ทเซิร์ฟเวอร์** (ค่านี้อ่านตอนสตาร์ตครั้งเดียว)
5. เข้า `/admin/orders` แล้วกดปุ่ม **🔔 ส่งข้อความทดสอบ** เพื่อยืนยันว่าส่งได้จริง

จะตั้งผ่าน env ก็ได้: `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` `SMTP_TO`

**SMS แจ้งเตือน** ตั้งปลายทางไว้ที่เบอร์ร้านแล้วในส่วน `sms` ของ `secrets.json`
เหลือแค่สมัครบริการ SMS แล้วใส่ API key — **บริการ SMS มีค่าใช้จ่ายต่อข้อความ**

```jsonc
"sms": {
  "provider": "thaibulksms",   // หรือ "twilio"
  "to": "0849948889",
  "sender": "",                // ชื่อผู้ส่งที่ลงทะเบียนไว้ (Twilio = เบอร์ต้นทาง)
  "api_key": "",               // <- ใส่ตรงนี้ (Twilio ใช้ Account SID)
  "api_secret": ""             // <- (Twilio ใช้ Auth Token)
}
```

ผู้ให้บริการที่รองรับ: [ThaiBulkSMS](https://thaibulksms.com) · [Twilio](https://twilio.com)
env ที่ใช้ได้: `SMS_PROVIDER` `SMS_TO` `SMS_SENDER` `SMS_API_KEY` `SMS_API_SECRET`

> SMS ภาษาไทยคิด **70 ตัวอักษรต่อ 1 ข้อความ** (ภาษาอังกฤษ 160)
> ระบบจึงส่งเฉพาะใจความสั้น เช่น `ออเดอร์ใหม่ KS-260809-9F29 ยอด 1,198 บาท โทร 0812345678`
> (55 ตัวอักษร = 1 ข้อความ) ส่วนรายละเอียดเต็มจะไปทางอีเมล/webhook

การแจ้งเตือนส่งแบบเบื้องหลัง ถ้าปลายทางล่มหรือช้า จะไม่กระทบการสั่งซื้อของลูกค้า

## ที่เก็บข้อมูล

โฟลเดอร์ `app/_data/` (อยู่ใน `.gitignore` — ห้าม commit)

| ไฟล์ | เก็บอะไร |
|---|---|
| `orders.json` | คำสั่งซื้อและสถานะ |
| `payments.json` | รายการแจ้งชำระเงิน |
| `messages.json` | ข้อความจากฟอร์มติดต่อ |
| `slips/` | ไฟล์สลิป — อยู่นอก `/static` เปิดดูได้เฉพาะแอดมิน |
| `secrets.json` | secret key และรหัสผ่านแอดมิน |

## ข้อจำกัดที่ยังไม่ได้แก้

- **สต็อกยังไม่ถูกตัด** ตอนสั่งซื้อ — สั่งเกินจำนวนที่มีได้
- หน้า 404 / 500 ยังเป็น JSON ดิบ ไม่ใช่หน้าเว็บ
- เลขบัญชีธนาคารและพร้อมเพย์ยัง hardcode อยู่ใน `app/route/payment.py`
- ข้อมูลเก็บเป็นไฟล์ JSON ยังไม่มีฐานข้อมูล
- `app/main.py` ตั้ง `https_only=False` — ถ้า deploy ด้วย HTTPS ให้เปลี่ยนเป็น `True`
